# Desafio de Projeto: Evolução Automotiva em HTML5 🏎️

Este projeto foi desenvolvido como parte do desafio técnico do Módulo I da Trilha de HTML da [Nome da Instituição/DIO]. O objetivo foi criar uma página web estruturada utilizando exclusivamente tags semânticas e de formatação de texto.

## 🛠️ Tecnologias Utilizadas
* **HTML5** puro (sem CSS ou JavaScript).

## 🚀 Evolução e Melhorias
A partir da versão inicial, o projeto passou por uma refatoração para atender a 100% dos requisitos do desafio e boas práticas de desenvolvimento:

1.  **Semântica Corrigida:** Removi listas (`<ul>` e `<ol>`) que estavam dentro de parágrafos (`<p>`), garantindo que o código siga os padrões da W3C.
2.  **Hierarquia de Títulos:** Implementei a escala completa de cabeçalhos, do `<h1>` ao `<h6>`, organizando melhor a leitura.
3.  **Formatação Avançada:** Adicionei tags de contexto científico e técnico, como:
    * `<sub>` e `<sup>` para fórmulas químicas (H₂O) e potências matemáticas.
    * `<abbr>` para acessibilidade em siglas como IA e GPS.
    * `<blockquote>` para citações externas.
4.  **Navegação Interna:** Criação de um índice com âncoras (`href="#id"`) para facilitar a navegação em páginas longas.
5.  **Tags de Estilo Físico e Lógico:** Inclusão de `<mark>`, `<del>`, `<font>`, `<strong>` e `<i>` para destacar pontos críticos do texto.
